# DotFluent

DotFluent is a library providing a set of extension members for commonly used types within .Net (C#) to enable writing code fluently.
It also adds support for different patterns like the option or result pattern (unions) and further enhances .Net features like LINQ 
by adding more methods and overloads to existing methods as well as bringing promise like extensions to .Net Tasks.

### Where can I get it?

You can use the [NuGet](https://learn.microsoft.com/nuget/install-nuget-client-tools) package manager console to install [DotFluent](https://www.nuget.org/packages/DotFluent/):

```
PM> Install-Package DotFluent
```
Or use the [.Net CLI](https://dotnet.microsoft.com/download):
```
dotnet add package DotFluent
```

For more installation options visit the [DotFluent](https://www.nuget.org/packages/DotFluent/) NuGet package overview.
